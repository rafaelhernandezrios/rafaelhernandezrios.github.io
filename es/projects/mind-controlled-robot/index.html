Brazo robótico controlado con la mente

Entrena un modelo con tu propio EEG y luego mueve un Dobot Magician pensando en ello.

Año
2025 – 2026
Mi rol
Desarrollador · instructor del taller
Stack
Pythonscikit-learnLSLDobot MagicianTCP socketsTkinter

El problema

Las interfaces cerebro–computadora se sienten abstractas para los estudiantes; necesitan una demo tangible y segura que puedan calibrar ellos mismos en una sesión.

Qué construí

  1. GUI que conecta el robot (serial) y el EEG (LSL), corre un protocolo corto de entrenamiento y ajusta un modelo de regresión.
  2. Lazo de control en tiempo real con posición segura de inicio y secuencias de prueba manuales.
  3. Un servidor TCP/IP para que todo un grupo controle un mismo robot desde sus laptops, con Python o con una GUI de botones.

Resultado

Hecho para los talleres de robótica y neurotecnología de Mirai.
