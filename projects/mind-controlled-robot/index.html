Mind-Controlled Robot Arm

Train a model on your own EEG, then move a Dobot Magician by thinking about it.

Year
2025 – 2026
My role
Developer · workshop instructor
Stack
Pythonscikit-learnLSLDobot MagicianTCP socketsTkinter

The problem

Brain–computer interfaces feel abstract to students; they need a tangible, safe demo they can calibrate themselves in one session.

What I built

  1. GUI that connects the robot (serial) and the EEG (LSL), runs a short training protocol and fits a regression model.
  2. Real-time control loop with safe home position and manual test sequences.
  3. A TCP/IP server so a whole class can command one robot from their own laptops, in Python or with a button GUI.

Outcome

Built for Mirai’s robotics and neurotechnology workshops.
